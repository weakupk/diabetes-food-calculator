# 糖食助手 / diabetes-food-calculator

一个 **Flutter + SQLite 的离线优先 MVP**，用于：

- 记录餐次与食物重量
- 按每100克营养值计算碳水、蛋白质、脂肪
- 维护中文食物库与自定义食物
- 按用户自定义公式拆分计算胰岛素（碳水部分、蛋白质/脂肪部分）

## 重要安全说明

**这是营养记录和公式计算工具，不是医疗设备或自动给药工具。所有参数和实际剂量必须由医生或糖尿病教育师确认。**

第一版有意 **不** 包含：

- 高血糖修正
- 活性胰岛素扣除
- 自动用药建议
- 登录、后端或任何网络依赖

## MVP 能力

- 简体中文界面
- 本地 SQLite 存储
- 首次启动自动建库并初始化中文示例食物：米饭、鸡胸肉、西红柿、鸡蛋、苹果
- 食物支持中文名称和别名搜索
- 支持新增、编辑、删除自定义食物
- 支持新建早餐、午餐、晚餐、加餐、自定义餐次
- 单个餐次可添加多种食物，按重量实时计算营养
- 每种食物和本餐合计都同时显示：**重量、碳水、蛋白质、脂肪**
- 历史餐次支持查看、编辑、删除
- `meal_items` 保存食物名称和营养快照，避免后续修改食物库影响历史记录
- 支持多个胰岛素方案
- 胰岛素结果拆分显示：**碳水部分、蛋白质/脂肪部分、合计**
- 支持三种蛋白质/脂肪公式，并可编辑相关系数与舍入刻度
- 显示可展开的计算过程

## 胰岛素公式

1. **碳水胰岛素** = 本餐总碳水 ÷ 碳水系数
2. **蛋白质/脂肪胰岛素** 三选一：
   - 直接加权：`蛋白质克数×蛋白质系数 + 脂肪克数×脂肪系数`
   - 等效碳水：`(蛋白质克数×蛋白质换算系数 + 脂肪克数×脂肪换算系数) ÷ 碳水系数`
   - 合计克数：`(蛋白质克数 + 脂肪克数) ÷ 蛋白质脂肪系数`

## 本地运行

```bash
flutter pub get
flutter run
```

首次启动会在本地 SQLite 中初始化一次中文示例食物数据，后续重新打开不会重复插入。核心功能不依赖网络，断网后仍可搜索本地食物、编辑餐次、查看历史和按已保存方案进行公式计算。

## 测试覆盖

当前增加了以下重点测试：

- 非整百克营养计算（150g 米饭）
- 多食物合计
- 三种蛋白质/脂肪公式
- 舍入刻度
- 非法系数
- 不舍入 / 0.5U / 1U 舍入策略
- 历史餐次快照不受食物库修改影响
- 示例食物只初始化一次，不重复插入

## 本地存储与离线

- 所有食物、餐次、历史快照和胰岛素方案均保存在本地 SQLite。
- `meal_items` 会保存食物名称和每100克营养快照，后续修改食物库不会影响历史餐次。
- 目前没有账号、云同步或网络接口；这保证了断网可用，但也意味着数据不会自动同步到其他设备。

## 医疗安全边界

- 仅用于记录和公式计算，不构成医疗建议。
- 参数和实际剂量需由医生或糖尿病教育师确认。
- 本项目不会提供高血糖修正、活性胰岛素扣除或自动给药建议。

## 已知限制

- 当前食物搜索支持名称和别名匹配，不包含拼音、条形码或 AI 识别。
- 舍入模式仅提供：不舍入、0.5U、1U。
- 目前没有云备份；如需迁移数据，请自行备份本地数据库文件。
